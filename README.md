 **Old Portfolio — Classic Frontend Portfolio Website**

A personal portfolio website built with **HTML, CSS, and JavaScript**. This is one of my earlier versions of a developer portfolio, created before I moved to React-based projects. It showcases my initial work, layout skills, and understanding of clean UI structure.

🔗 **Live Demo:** https://xenia19.github.io/old-portfolio/
📦 **Repository:** [https://github.com/xenia19/old-portfolio](https://github.com/xenia19/old-portfolio)

📱 **About**

Portfolio is a static website built without frameworks, using only core frontend technologies. It includes structured sections like Projects, About, and Contact. The site focuses on layout design, typography, responsive blocks, and organizing project information in a clear way.

Although this is an early version of my portfolio, it reflects my foundation in **vanilla frontend development** and shows how I approached design and layout before transitioning to modern stacks.


🛠 **Tech Stack**

* **HTML5** — Structure
* **CSS3** — Styling, layout, media queries
* **JavaScript** — Interactive elements
* **GitHub Pages** — Deployment
